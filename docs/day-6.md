# Day 6：跨用例流程变量

验收日期：2026-11-25（Asia/Shanghai）。分支：`codex/day-6-flow-variables`。

## 本阶段结果

支持创建订单 → 从 JSON 响应提取 order_id → 后续查询与断言引用该 ID 的顺序流程。变量每次运行重新建立；失败步骤不导出，缺失变量的依赖步骤跳过，不发送请求。独立步骤仍继续执行。

变量仅做完整字段的数据替换，不执行表达式或代码；仅支持非 null 标量。每条用例最多 10 项提取，每值最多 4 KiB；变量名最长 64 字符，JSON Pointer 最长 200 字符。请求替换后仍受 64 KiB 输入限制。已知敏感字段和遮盖结果禁止导出。变量先全部验证再原子导出，避免部分成功污染后续步骤。

保存与运行时检查依赖顺序和重复导出。运行开始冻结配置与项目地址；每步保存模板快照、实际请求输入及导出值。旧用例与历史记录兼容，未新增数据库列或依赖。

## 保留限制与后续方向

本阶段为本地单用户、单进程、单 worker 的同步执行器；原有每集 10 条和总时限 30 秒继续生效。没有后台任务队列或自动重试。

不支持认证注入、初始/全局变量、复杂对象提取、字符串拼接、动态键名或脚本。已知敏感字段遮盖不是完整秘密识别，应仅使用测试数据。下一阶段可增加独立的认证配置与请求注入，再继续 Schema 断言及 AI 生成；当前尚未实现这些能力。

Docker、CI、生产部署和性能基准未在本阶段验证。
